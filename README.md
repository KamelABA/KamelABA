I'm a Software Engineering master's student based in Algeria, interested in turning practical problems into useful software. My work brings together **mobile and web development** with **applied AI and computer vision**—from designing an application experience to building the API and exploring how machine-learning models can support it.

I'm especially interested in projects with a clear real-world purpose, including civic technology and tools that make visual information more useful. I learn by building, testing ideas, and improving them through hands-on projects.

## 🎯 Career Focus

- **Software engineering:** building maintainable applications and end-to-end features.
- **Mobile and web development:** creating user-focused products with React Native, Expo, React, and Next.js.
- **Backend development:** developing APIs and working with data using FastAPI, Node.js, MongoDB, and PostgreSQL.
- **Applied AI and computer vision:** exploring image-based detection and classification with Python, OpenCV, TensorFlow, and PyTorch.

## 🌟 Selected Projects

### 🚧 Bilagh — Road Damage Reporting System
A mobile application concept for reporting road damage, combining location-aware submissions and map-based discovery with AI-assisted image classification.

- **App:** React Native and Expo
- **API and data:** FastAPI and MongoDB
- **Computer vision:** YOLO-based damage detection
- **Location and maps:** GPS and Leaflet

### 🌱 Plant Disease Detection
An application exploring computer vision and deep learning to identify plant diseases from images.

- **Stack:** Python, Flask, OpenCV, YOLO, and TensorFlow
- [View the repository](https://github.com/KamelABA/plant-disease-detection)
