## Featured Projects

### Bilagh — Road Damage Reporting System
A mobile application designed to help citizens report road damage through image-based detection, GPS coordinates, and map visualization.

- React Native and Expo for the mobile experience
- FastAPI and MongoDB for the backend and data layer
- YOLO-based computer vision for damage identification
- GPS and Leaflet for location-aware reporting

### Plant Disease Detection
An AI-powered application focused on detecting plant diseases using computer vision and deep learning techniques.

- Python and Flask for model integration and API exposure
- YOLO and TensorFlow for detection and classification workflows
- OpenCV for image processing and preprocessing

🔗 [View Repository](https://github.com/KamelABA/plant-disease-detection)
